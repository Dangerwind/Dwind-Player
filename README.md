**Dwind Player** — это приложение для тех, кому важно знать темп музыки. Оно проигрывает
аудиофайлы прямо с устройства, раскладывает их по папкам и плейлистам, а главное — умеет
определять **BPM** (beats per minute, удары в минуту) как автоматически, так и вручную.

Встроенный анализатор работает полностью **офлайн** и **на устройстве**: аудио никуда не
отправляется. Плеер показывает цифру темпа, подсказывает стиль трека и подсвечивает,
насколько можно доверять автоопределению.

> Приложение создано с использованием ИИ-агентов.

## ✨ Возможности

### 🗂️ Папки и библиотека
- Просмотр локальной музыки прямо с устройства через **MediaStore**, без импорта файлов.
- Навигация по папкам с кнопкой «Назад» и сохранением текущего пути.
- Отображение имени файла, названия трека и исполнителя.
- Сортировка списка:
  - **«Имя»** — по имени файла,
  - **«Название»** — по названию трека,
  - **«BPM»** — по темпу (треки без BPM уходят в конец).
- Повторный тап по активной сортировке меняет направление (по возрастанию / по убыванию).

### 📃 Плейлисты
- Создание, переименование и удаление плейлистов.
- Добавление треков из библиотеки множественным выбором («Выбрать все» / «Снять все»).
- Удаление отдельных треков из плейлиста.
- Собственный BPM-анализ всего плейлиста.
- Плейлист — это отдельная коллекция, к которой можно вернуться под настроение.

### 🥁 Работа с BPM
- **Автоопределение** темпа для одного трека (кнопка «Спидометр» на строке трека).
- **Пакетный анализ**: измерение BPM всех треков папки или плейлиста одним нажатием,
  с индикатором прогресса, счётчиком `готово/всего` и возможностью отмены.
- **Ручной ввод** и **tap-tempo**: тап по цифре BPM открывает диалог, где можно
  «простучать» темп или ввести значение вручную.
- **Выбор стиля (жанра)** вручную из списка (Электроника, Рок, Рок-н-ролл, Поп, Хип-хоп,
  Джаз, Блюз, Классика, R’nB/Соул, Регги, Фолк, Метал, Панк, Drum’n’Bass, Иное).
- **Уверенность определения** показывается цветом цифры BPM:
  - 🔵 **синий** — ручной BPM (tap-tempo или ввод),
  - 🟢 **зелёный** — авто, уверенность не ниже заданного порога,
  - 🟡 **жёлто-коричневый** — авто, уверенность ниже порога.
- BPM кэшируется в локальной базе и не пересчитывается без необходимости.
  Уже посчитанный трек можно **пересчитать** принудительно.
- Ручной BPM имеет приоритет над автоматическим.

### ▶️ Плеер
- Мини-плеер поверх списка с прогресс-баром, который можно **перетаскивать** для перемотки.
- Управление: воспроизведение/пауза, следующий/предыдущий трек.
- **Перемешивание (shuffle)** и **повтор** (по кругу / один трек).
- Кнопка **«+»** — добавить текущий трек в плейлист одним тапом (иконка меняется на 📚,
  если трек уже в плейлистах). Под плеером видно, в каких плейлистах состоит трек.
- Показ BPM и жанра текущего трека прямо в плеере.
- Воспроизведение продолжается в фоне и из уведомления (MediaSessionService).

### 🎛️ Настройки и оформление
- **Тема**: как в системе / светлая / тёмная.
- **Диапазон BPM** (по умолчанию 40–255): сужение диапазона убирает ложное удвоение темпа
  и ошибки распознавания.
- **Порог «зелёного» BPM** (50–100%, по умолчанию 75%): в этом диапазоне настраивается,
  при какой уверенности цифра становится зелёной.
- Переключатель **«Отображать стиль»** — показывать или скрывать жанр.
- **«О программе»** — версия, дата сборки, ссылка на профиль разработчика.

### 📖 Помощь (интерактивный гид)
- Запускается из меню → **«Помощь»**.
- Гид **контекстный**: он показывает только те шаги, элементы которых реально есть на
  текущем экране, и ведёт по ним, соединяя облачко подсказки с нужной кнопкой линией.
- В конце — блок **«Что ещё умеет»** с подсказками о возможностях, которых сейчас не видно.
- Кнопки **«Далее»** и **«Закончить»**; облачко выделено рамкой и тенью (в т.ч. в тёмной теме).

### 📱 Адаптивный интерфейс
- Телефон, ландшафт и планшет получают разную раскладку: компактная шапка в ландшафте,
  читаемый заголовок на узком экране, полная раскладка на планшете.
- Плавающие кнопки («+» создать плейлист / добавить треки) позиционируются **над мини-плеером**
  по его реальной измеренной высоте.
- Выбранная вкладка, открытый плейлист и экран выбора треков **сохраняются при повороте экрана**.
- Поддержка edge-to-edge и системных отступов.

## 🎵 BPM: как это работает

Определение темпа — это собственный офлайн-движок **`EnsembleBpmDetector`** (`bpm/`),
написанный без внешних DSP-библиотек. Пайплайн:

```
извлечение аудио (MediaExtractor / MediaCodec, до ~50 секунд из середины трека)
        ↓
DC-removal и децимация до 22 050 Гц
        ↓
STFT (окно Ханна, перекрытие 75%)
        ↓
мультиполосная спектральная флюенция + комплексно-доменная разница
        ↓
сглаживание, локальная нормировка, объединение полос (низ / середина / верх)
        ↓
темпограмма (автокорреляция по окнам)
        ↓
кросс-корреляционные кандидаты
        ↓
разрешение октав (×0.5, ×1.5, ×2)
        ↓
гребёнчатый фильтр (проверка долей и меж-долей)
        ↓
мягкий жанровый / априорный приоритет → уверенность 0..1
```

Особенности:

- **Не загружает файл целиком** — анализирует репрезентативный фрагмент (около 50 секунд),
  поэтому работает быстро и бережно к памяти.
- **Ансамблевый подсчёт** — объединяет несколько методов оценки и голосование по кандидатам,
  что снижает типичные ошибки «в два раза».
- **Мягкая жанровая классификация** (`GenreClassifier`) — по акустическим признакам
  (низ/середина/верх, яркость, ритмичность, резкость) оценивает вероятный стиль и слегка
  корректирует скор. Жанр **не ограничивает** диапазон темпа и используется только как подсказка.
- **Ручной BPM приоритетнее** автоопределения и хранится отдельно (`source = manual`).
- Результаты кэшируются в Room (таблица `bpm_library`), кэш обновляет интерфейс в реальном времени.

## 🛠️ Технологии

| Слой | Технологии |
|------|-----------|
| Язык | **Kotlin 2.0** |
| UI | **Jetpack Compose**, **Material 3**, Material Icons Extended |
| Асинхронность | Kotlin **Coroutines** и **Flow** / StateFlow |
| Воспроизведение | **AndroidX Media3** (ExoPlayer + MediaSessionService) |
| Локальное хранилище | **Room** (треки, плейлисты, BPM-кэш) |
| Настройки | SharedPreferences (обёрнуты в `StateFlow`) |
| Медиа-доступ | **MediaStore** (ContentResolver) |
| Аудиодекодирование | Платформенные **MediaExtractor / MediaCodec** (без сторонних DSP-библиотек) |
| Сборка | **AGP 8.7.2**, Gradle Kotlin DSL, KSP (для Room), JUnit |
| Минимальная версия | Android 7.0 (API 24), target/compile SDK 34 |

> Анализ BPM написан полностью вручную: внешние библиотеки вроде TarsosDSP не используются.

## 🏗️ Архитектура

Приложение построено по слоям, с односторонним потоком данных
(UI → ViewModel → Repository → данные), и переживает поворот экрана.

```
com.dwind
├── MainActivity              — точка входа, тема, edge-to-edge
├── DwindApp                  — Compose-корень, вкладки, навигация
│
├── ui/                       — интерфейс (Compose)
│   ├── DwindApp.kt           — шапка, вкладки, мини-плеер, шаги гида
│   ├── Adaptive.kt           — признаки размера окна (телефон/ландшафт/планшет)
│   ├── screens/
│   │   ├── folders/          — браузер папок
│   │   └── playlists/        — список, детали и выбор треков плейлиста
│   ├── components/           — общие элементы (плеер, BPM, меню, диалоги)
│   ├── help/                 — интерактивный гид «Помощь»
│   └── viewmodel/            — Player, Folders, Playlists, PlaylistDetail
│
├── bpm/                      — движок темпа
│   ├── BpmAnalyzer.kt        — декодирование и запуск анализа
│   ├── EnsembleBpmDetector   — ансамблевый детектор BPM
│   └── GenreClassifier.kt    — мягкая жанровая классификация
│
├── data/
│   ├── repo/                 — AudioRepository, BpmRepository
│   ├── local/                — Room: база, DAO, сущности
│   └── model/                — AudioItem, BpmInfo
│
├── playback/                 — PlaybackService + PlaybackConnection (Media3)
└── settings/                 — AppSettings (настройки на StateFlow)
```

Разделение ответственности:

- **UI** — только отображение и отправка событий.
- **ViewModel** — состояние экрана (`StateFlow`), сценарии использования, работа с плеером.
- **Repository** — доступ к данным (MediaStore, Room, BPM-кэш).
- **Детектор BPM** — чистый вычислительный модуль, покрыт юнит-тестами.

## 🚀 Сборка и установка

### Требования
- **Android Studio** (Ladybug или новее) либо Android SDK из командной строки;
- **JDK 17**;
- Android SDK с установленными платформами (compile SDK 34).

### Debug-сборка
```bash
./gradlew :app:assembleDebug
```

Готовый APK появится по пути:

```
app/build/outputs/apk/debug/dwind-debug.apk
```

### Release-сборка
```bash
./gradlew :app:assembleRelease
```

Имя файла — `dwind-release-unsigned.apk` (для публикации подпишите его своим ключом).

### Установка на устройство
```bash
adb install -r app/build/outputs/apk/debug/dwind-debug.apk
```

### Тесты
```bash
./gradlew :app:testDebugUnitTest
```

Покрыты определение BPM (`BpmAnalyzerUnitTest`), классификация жанров (`GenreClassifierTest`)
и логика сортировки (`SortingTest`).

## 🔐 Разрешения

| Разрешение | Зачем нужно |
|------------|-------------|
| `READ_MEDIA_AUDIO` (Android 13+) | доступ к аудиофайлам устройства |
| `READ_EXTERNAL_STORAGE` (API ≤ 32) | доступ к аудиофайлам на старых версиях |
| `FOREGROUND_SERVICE` | фоновое воспроизведение |
| `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | воспроизведение через сервис медиасессии |
| `POST_NOTIFICATIONS` | управление плеером из уведомления |

Приложение **не отправляет** музыку и метаданные в интернет: весь анализ выполняется офлайн.

## ⚠️ Ограничения

- Определение BPM **не гарантирует 100% точность** для любого трека.
- Возможна путаница между **половинным и двойным** темпом — частично решается сужением
  диапазона BPM в настройках.
- Некоторые форматы или повреждённые файлы могут не декодироваться.
- Фоновый анализ ограничен ресурсами устройства: нагрузка распределяется по числу ядер CPU.
- Жанровая оценка — **мягкая подсказка**, а не точная классификация.
